# Content Delivery Networks (CDN)

> Part of `01-foundations/`. Scaffolded during Phase 3 of the repo restructure — this lab currently contains references and a notebook plan; notebooks will be added incrementally.

## Learning objectives

- Explain what a CDN is and why it reduces latency and origin load.
- Compare push and pull CDN models and choose between them.
- Walk through a request from user → edge → origin, including cache hits, misses, and revalidation.

## Concepts covered

- Origin vs edge servers
- Pull CDN vs Push CDN
- Cache hit ratio, TTL, revalidation
- When to use CDN vs serving directly from origin
