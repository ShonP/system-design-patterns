# Content Map

> Status: **Stub** — living document that maps scraped Design Gurus lessons
> (`scraper/designgurus/content/`) to labs in this repository.
>
> This file will be generated (Phase 4) from the scraped content index and then
> hand-curated. For now it is intentionally empty.

## How to use

1. Each row maps one scraped lesson to the lab that should absorb it.
2. If no lab exists yet, the row should point to a **proposed** lab path; that
   lab will be created in Phase 3/4.
3. When a new lesson arrives on a topic that already has a lab, the row marks
   the lab as the target — we **enrich** existing labs rather than create
   sibling labs.
